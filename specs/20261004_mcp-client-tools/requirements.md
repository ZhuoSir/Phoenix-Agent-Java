## 背景与目标

**勘察事实（2026-10-04，代码为准）**：
- 平台已具 **MCP Server 端**（`@McpServerTool` + `McpServerToolUtil`，暴露 nl2sql/agent 列表）
- AgentScope 框架已具**完整 MCP Client 栈**：core `McpClientBuilder` 四传输（stdio/SSE/StreamableHTTP/HTTP）；harness `McpServerRegistrar.register(Toolkit, Map<String,McpServerConfig>)`（自带 enableTools 过滤+双超时）；`HarnessAgent.getToolkit()` 公开——**框架零改造，纯接线**
- 组授权先例齐备：智能体↔组（`tbl_platform_group_agent_info`）、技能发布授权组（agent-skill-management 已交付）——本需求权限模型与之同构

**目标**：admin 新增「插件市场 → 插件管理」体系，首类插件 = **MCP**（统一管理：列表/详情/配置/增删改查），权限与**用户组**关联（与智能体、技能同构）；智能体绑定 MCP 后，对话中模型可调用其工具；未来扩展 API 插件（BL-25 待办，本期不做）。

**成功画面**：管理员在插件市场录入一个 MCP Server（如自家 nl2sql 端点）→ 测试连接看到工具清单 → 授权给若干用户组 → 在智能体编辑页绑定 → 该组前台用户与智能体对话时模型自主调用 MCP 工具出结果；Server 宕机对话照常。

## 需求条款（EARS）

### R-01 插件市场与 MCP 统一管理（admin）
系统 SHALL 在 admin 新增「插件管理」顶级菜单，其下含 **MCP** 类型页（架构预留 API 插件扩展位，BL-25 本期不做）；MCP 页 SHALL 提供：列表（名称/传输类型/状态/授权组数/被绑定智能体数，支持搜索分页）、详情（配置只读态+工具清单+授权与绑定情况）、新建/编辑/删除/启用停用；配置项含：名称、传输类型（stdio/SSE/StreamableHTTP/HTTP）、endpoint URL 或 command+args、鉴权 headers/env、enableTools 工具过滤（空=全部）、连接与调用超时。

**验收场景**
- GIVEN 管理员 WHEN 新建 MCP 配置并保存 THEN 列表可见、详情可查、编辑可改、停用后不再参与任何挂载。
- GIVEN MCP 被智能体绑定中 WHEN 删除 THEN 系统 SHALL 阻止或明示级联影响（解绑后才可删，plan 定细节），不得静默产生悬挂引用。

### R-02 组授权（与智能体/skill 同构）
WHEN 管理员在 MCP 详情/编辑中多选用户组授权, 系统 SHALL 持久化授权关系且即时生效；授权语义与既有智能体/技能组授权同构（数据模型、管理端交互、前台可见性判定同源）。

**验收场景**
- GIVEN MCP-S1 授权给组 G1 WHEN G1 内前台用户使用绑定了 S1 的智能体 THEN S1 工具可用；G2（未授权）用户同智能体对话 THEN S1 工具不挂载。
- GIVEN 撤销 G1 授权 WHEN G1 用户下一轮对话 THEN S1 工具不再挂载（生效粒度=轮次）。

### R-03 智能体绑定与对话挂载
系统 SHALL 支持在智能体编辑页多选绑定 MCP（与技能/知识库绑定交互同构）；WHEN 对话轮次开始, 系统 SHALL 将「智能体已绑定 ∧ 当前用户所属组已授权」交集内的启用 MCP 的工具挂载进本轮工具集（管理端 admin 对话的权限口径 plan 勘察后定，与技能现行口径一致），工具呈现带来源标识防同名冲突，模型调用结果回注推理循环。

**验收场景**
- GIVEN 智能体 A 绑定 S1（G1 已授权）WHEN G1 用户对话问及相关能力 THEN 模型可见并调用 S1 工具（回环用例：绑定平台自家 nl2sql MCP 端点完成数据问答）。
- GIVEN 两 MCP 有同名工具 WHEN 同轮挂载 THEN 以来源标识区分共存。

### R-04 故障隔离
IF 某 MCP Server 连接失败/初始化超时/调用中异常, THEN 系统 SHALL 隔离故障（跳过该 Server 或给模型可读错误），主对话循环、其他 MCP、内置工具 SHALL 不受影响，WARN 日志含 server 名与原因。

**验收场景**
- GIVEN 绑定了坏 endpoint WHEN 对话 THEN 对话正常（其余工具可用），日志 WARN 指明该 Server。
- GIVEN 调用中途断连 WHEN 模型调用该工具 THEN 模型收到可读错误可自行改道，轮次不崩。

### R-05 安全边界
WHERE 配置 stdio 类型（服务端拉起进程）, 系统 SHALL 仅管理员可配并明示风险+留痕（操作人/时间/命令）；鉴权 env/headers 敏感值 SHALL 脱敏存储与回显（沿用 api_key `sk-xxxxx` 先例），明文仅连接时使用；插件市场全部管理面 SHALL 仅 admin 端可见（前台用户零配置入口，仅按组消费）。

**验收场景**
- GIVEN 保存含密钥的 stdio 配置 WHEN 重开编辑页/查库 THEN 回显脱敏、落盘无明文（或加密，plan 定）。
- GIVEN 前台任意用户 WHEN 访问插件市场相关接口 THEN 403/不可见。

### R-06 连接测试
WHEN 管理员点击「测试连接」, 系统 SHALL 按当前表单即时试连并回显：成功=协议版本+工具数+工具名列表；失败=可读原因（不可达/鉴权失败/超时），测试 SHALL 不落库不影响既有配置。

**验收场景**
- GIVEN 有效 SSE endpoint WHEN 测试 THEN 数秒内回显工具清单。
- GIVEN 错误鉴权 WHEN 测试 THEN 回显鉴权失败而非笼统超时。

### R-07 平台 MCP Server 端零变化（身份矩阵对面）
既有平台 Server 端（@McpServerTool 暴露面）行为 SHALL 逐字节不变；本需求改动 SHALL 不触碰其注册/暴露/协议路径。

**验收场景**
- GIVEN 部署新版本 WHEN 外部 Client 调用平台既有 MCP 端点 THEN 工具列表与行为与旧版一致（plan 身份矩阵枚举断言）。

## Non-goals（范围外）
- **API 插件类型实现**（架构留扩展位，功能=BL-25 待办）
- MCP 配置市场/模板库/跨环境同步
- OAuth2 等复杂鉴权流（v1 = headers/env 静态凭据）
- 平台 MCP Server 端功能扩展（R-07 只保不变）
- stdio 进程沙箱强化（v1 = 管理员信任+留痕+容器天然隔离）
- 对话轮次中途热加载工具（生效粒度=轮次）
- 前台用户自助配置/申请 MCP

## 我正在做的假设
- **A-1** 生效粒度=轮次：授权/绑定/启停变更至迟下一轮对话生效，不重启服务
- **A-2** 数据模型新增 MCP 注册表+组授权表+智能体绑定表（与技能三件套同构；Flyway 件 plan 定，含菜单/权限种子 DML）
- **A-3** 四传输全开放；stdio 受 R-05 约束
- **A-4** enableTools 空=全挂载；工具来源标识格式以框架 McpTool 实际命名为准（plan 核）
- **A-5** admin 端对话的挂载口径与技能现行口径一致（plan 勘察后写死，不新造语义）
- **A-6** 菜单落位：插件管理为顶级菜单，MCP 为其下类型页（2026-10-04 用户二次裁决：市场层去除，本质同一）
