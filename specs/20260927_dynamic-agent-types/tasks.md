# 任务清单：对话智能体统一化与去硬编码

> 验证口径：项目无测试基建（profile §测试基线），验证以「curl + SQL 断言 + 浏览器人工走查 + 真实对话链路」为主，编译/lint 仅兜底，全部留真实输出。

## 1. 基础（库表与配置模型）

- [x] T-01 编写并本地执行 03 升级件（新表 + type 默认值/NULL 回填）与回滚脚本
  关联: R-01, R-11
  依赖: 无
  验证方式: 在本地 phoenix-pg 执行升级→`\d tbl_data_agent_runtime_config` 结构齐备、`select count(*) from tbl_data_agent where type is null` 为 0、`type` 列默认值生效（插入不带 type 的行后取值 = harness）；执行回滚后对象消失；空库重放两顺序零报错（psql 输出留档）
  验收标准: 升级/回滚脚本幂等可重放；NULL 回填不可逆性在脚本注释与 artifacts.md 中注明

- [x] T-02 新增运行配置实体/Mapper、开关枚举与 DTO/VO
  关联: R-03, R-09
  依赖: T-01
  验证方式: `mvn install -pl phoenix-agent/phoenix-agent-core -am` 编译通过；字段与 DDL COMMENT 逐一对齐（人工比对清单）
  验收标准: 无魔法值（开关/策略全枚举）；VO 不暴露内部审计字段

- [x] T-03 实现 RuntimeConfigService：读写（缺省返回默认值）+ 参数校验
  关联: R-03, R-05, R-09
  依赖: T-02
  验证方式: curl（待 T-04）三分支：无配置→返回默认；开数据库工具未选数据源→参数错误；工具数超上限→错误
  验收标准: 校验规则集中在该服务；异常返回明确错误码不抛裸异常

- [x] T-04 挂载 REST：GET/PUT `/api/agent/{id}/runtime-config`；`POST /api/agent` 强制 `type=harness`；`PUT` 不改写 type
  关联: R-01
  依赖: T-03
  验证方式: curl：新建（不传 type）→ 落库 type=harness；更新存量 sql 智能体（请求带 type=harness）→ 落库 type 仍为 sql；配置读写往返一致；未登录 401
  验收标准: 服务端强制优于入参；存量类型不被改写

## 2. 运行时（Factory / Registry / 工具）

- [x] T-05 实现 HarnessAgentFactory：按运行配置构建 HarnessAgent，工具按 agent 实例化绑定
  关联: R-03
  依赖: T-02, T-03
  验证方式: 单元级验证缺失→以 T-11/T-16 的真实对话链路替代：临时端点或启动日志中打印某 agentId 的构建摘要（工具清单/模型/技能池大小）
  验收标准: 构建过程无 Java 自注册依赖；工具清单与运行配置开关一致

- [x] T-06 实现 HarnessAgentRegistry：agentId→实例、配置指纹失效、LRU 上限、close；存量 sn 回退
  关联: R-02, R-03, R-08
  依赖: T-05
  验证方式: 真实调用：改动运行配置后下一次对话生效（重建）；连续调用命中缓存（日志计数）；存量制度专家（sn 路径）对话仍可用
  验收标准: 无 `sn || id` 兜底；实例淘汰时调用 close 且不关闭共享仓库

- [x] T-07 泛化知识库工具 KnowledgeRetrievalTool（去掉写死 agentId=18，按 agent 配置查询）
  关联: R-04
  依赖: T-05
  验证方式: 建两个对话智能体分别启用知识库、挂不同知识范围 → 各自对话中检索结果来自其自身范围（对话留证 + 日志打印命中的 agentId/topK）
  验收标准: 代码中不再出现硬编码 agentId；topK/阈值来自配置

- [ ] T-08 实现取数工具 DatabaseQueryTool（NL→SQL→只读结果，复用 Nl2SqlService）
  关联: R-05
  依赖: T-05
  验证方式: 对已配数据源的对话智能体提问 → 返回真实数据（与直接查库结果一致）；未配数据源时调用返回明确错误；写操作语句被拒绝
  验收标准: 只读约束生效；错误信息可展示、不泄漏堆栈

- [ ] T-09 实现深度分析工具 DeepAnalysisTool（内部走 NL2SQL 状态图，独立 threadId + 并发限制）
  关联: R-05
  依赖: T-05
  验证方式: 复杂问题触发 → 返回分析结论/报告；对话主会话状态不被污染（会话消息与会话状态对比）；并发深度分析被限制并给出提示
  验收标准: threadId 隔离生效；超并发返回明确提示

- [x] T-10 AgentScopedSkillRepository 支持按 agentId 过滤（保留 sn 兼容路径）
  关联: R-03, R-10
  依赖: T-05
  验证方式: 新建对话智能体绑定技能 A、另一智能体绑定技能 B → 各自只感知自身技能；存量制度专家（sn 路径）技能仍生效（「报诗」类回归）
  验收标准: 双路径并存且互不影响；skills spec 前台技能区不回归
