# 需求规格：断线续传 / 流恢复（detached-stream，BL-22）

## 背景与目标

现状（三起实测事故坐实）：智能体一轮执行**绑定在浏览器 SSE 连接上**——刷新/断网/代理超时 → ①该轮静默夭折或结果丢失（13:30 png 事故）②助手消息只在前端收尾时落库，断流即蒸发（BUG-53：12:32 会话只有 user 行）③轮末文件扫描不执行，产物不进面板。心跳与 900s 超时（BUG-55）缓解了代理掐流，但**执行与连接解耦**未解决。

目标：**关页面≠杀任务**。服务端把当轮跑完并增量持久化；用户重进会话能看到「生成中」的实时内容并追上直播，完成后一切如常落库、登记、可回看。

## 需求条款（EARS）

- **R-01** WHEN 客户端连接在轮次执行中断开（刷新/断网/关闭页）, 系统 SHALL 继续完成该轮执行，不产生半途夭折。
- **R-02** WHILE 轮次执行中, 系统 SHALL **每 5 秒**增量持久化助手回答（含思考通道路由后的正文/思考两轨，Q4 拍板）；WHEN 轮次结束, 系统 SHALL 以最终内容覆盖定稿（同一消息，不产生重复行）。
- **R-03** WHEN 用户重进含「执行中轮次」的会话, 系统 SHALL **自动**展示已生成的增量内容并实时追流至完成（Q1 拍板；追流视图与正常直播一致：thinking/content/agentFiles 帧语义不变）。
- **R-04** WHEN 轮次完成且客户端不在线, 系统 SHALL 照常完成消息定稿落库与**轮末文件扫描登记**（产物不丢面板）。
- **R-05** 助手消息落库所有权 SHALL 移交服务端（按轮次幂等 upsert）；前端 onComplete 保存路径退役——消除双写与断流丢库两类缺陷。
- **R-06** WHEN 用户显式点击「停止生成」, 系统 SHALL 取消对应轮次；客户端断开本身不再构成停止语义（断≠停）。
- **R-07** IF 脱离式执行超过兜底时限 **10 分钟**（Q2 拍板）仍未完成, THEN 系统 SHALL 终止该轮并把已生成内容定稿（标注「超时中断」），资源随 TTL 回收。
- **R-08** 断线期间的 HITL 确认帧 SHALL 暂存（沿用 pending_confirm 持久化），重连追流时重新送达，确认/过期语义不变。
- **R-09** 前台聊天页与 admin 运行页 SHALL 行为一致；A′ 本地快照（若先行）与服务端增量冲突时**以服务端为准**去重。
- **R-10** IF 请求方未登录或非会话属主, THEN 系统 SHALL 拒绝其追流/查询他人在执行轮次（沿用属主鉴权口径）。

## 验收场景

- AC-01（续跑）发起一个 60s+ 的任务 → 中途刷新页面 → 重进会话：内容在增长直至完成，最终消息完整、无重复行。
- AC-02（产物不丢）断开状态下任务写出文件 → 完成后文件面板可见（R-04）。
- AC-03（显式停止）点「停止」→ 轮次真终止、内容定稿；关页面 → 轮次继续（对照）。
- AC-04（HITL 断线确认）任务挂起待确认 → 刷新 → 重进后确认按钮重现，确认后任务续跑。
- AC-05（越权）他人 token 追该会话流 → 拒绝。
- AC-06（兜底）构造超时限轮次 → 定时终止+「超时中断」标注+无资源泄漏（Redis TTL 清空）。

## Non-goals（范围外）

- 多标签页/多设备并发写同一会话的仲裁（一源一读即可）；消息编辑/重新生成产品化；跨重启的持久任务队列（进程重启仍在跑的轮次接受丢失并标「中断」，A′ 兜底显示）。
- BL-20 多智能体编排（其子任务视图建立在本基建之上，另单）。

## 决策记录（2026-10-02 用户四问全拍，皆选推荐项）

- Q1 重进行为 → **自动追流**（R-03）
- Q2 兜底时限 → **10 分钟**（R-07）
- Q3 节奏 → **A′ 先行 + B 主体**：A′（前端快照止血，原型在 stash）作为本 spec 一期先交付；B（服务端脱离执行）为二期。两期由 R-09 去重规则衔接（A′ 上线期即时有效，B 落地后服务端优先、A′ 退化为秒级窗口兜底）
- Q4 增量频率 → **5 秒**（R-02）

## 我正在做的假设（现在纠正，否则按此执行）

- A-01 轮次缓冲用 Redis（现网 db8 + Redisson 已有），不建 PG 轮次注册大表；断线重放以 Redis 流为准，终态由消息表定稿承载。
- A-02 进程重启丢在跑轮次（Non-goals 已言明），不做任务恢复队列。
- A-03 前端追流复用现有 SSE 消费链与帧协议（新增 join 端点，帧型不变）。
- A-04 增量持久化写同一行消息（uuid/turnId 主键 upsert），历史接口天然回显部分内容。
- A-05 挂 **v1.4.0**（M0 已立）。
