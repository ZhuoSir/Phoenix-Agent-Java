# 任务清单：品牌外观配置化（brand-configuration）

> 覆盖检查：R-01~R-08 均有任务覆盖（见各任务「关联」）。
> 共享面断言：T-02（匿名 GET 白名单）、T-06（6 处硬编码替换）、T-08（回归）。
> 日志断言：T-03/T-04 覆盖 plan §八 五条日志点。

## 组 1 · 后端基础

- [ ] T-01 建表迁移 + 默认值（= 现状硬编码）
  关联: R-04
  依赖: （无）
  验证方式: 应用 `V2.1.0_04__brand_config.sql` 后 `\d tbl_platform_brand_config` 断言字段与单行约束；
    查询默认行断言值等于现状（`systemName=Phoenix Agent`、`primaryColor=#1677ff`、`logoUrl=/imgs/logo.png`、
    `faviconUrl=/favicon.ico`）；重复执行幂等（第二次数 0 行变更）；rollback 件可执行。
  验收标准: 四条断言全过并贴输出。

- [ ] T-02 服务 + 匿名 GET（4 公开字段 + 60s 缓存）
  关联: R-01, R-02, R-03
  依赖: T-01
  验证方式: 无 token `curl GET /api/chat/attachment/...` 同款方式调 `GET /api/platform/brand-config` → 200 且
    **只含** `systemName/logoUrl/faviconUrl/primaryColor`；带 token 亦同；断言响应中**不含** updatedBy/updatedTime；
    日志断言缓存未命中 DEBUG 1 次、命中后不再打。
  验收标准: 字段白名单 + 无敏感字段 + 缓存日志三证齐全。

- [ ] T-03 超管更新接口（校验 + 审计 + 清缓存）
  关联: R-03, R-06
  依赖: T-02
  验证方式: 超管 PUT 合法值 → 200 且库/GET 均更新；非法值（名称 41 字 / `red` / `#12345`）→ 4xx 且带明确文案；
    **非超管 PUT → 拒绝**（种子普通管理员账号实测）；日志断言 `[brand] 更新 by=…` 1 条。
  验收标准: 三类断言全过；越权不落库。

- [ ] T-04 品牌图上传（2MB + 类型白名单 + 不开放 SVG）
  关联: R-02, R-06
  依赖: T-02
  验证方式: 上传 1 个 png → 返回 URL 且可访问；上传 >2MB → 拒绝；上传 `.svg` → 拒绝（文案说明仅位图/ico）；
    上传 `.exe` → 拒绝；日志断言 `[brand] 上传 by=… ext=… bytes=…`。
  验收标准: 四类文件行为正确 + 日志齐全。

## 组 2 · 前端接入

- [ ] T-05 品牌 store + 启动注入（失败回落默认，不阻塞）
  关联: R-01, R-02, R-03, R-04, R-05
  依赖: T-02
  验证方式: 正常网络：刷新后 title/favicon/CSS 变量与后端一致（DOM 断言 `document.title` 与 `--el-color-primary` 计算值）；
    模拟接口 500/超时：页面仍能打开（回落默认值），console 有 WARN 但不白屏。
  验收标准: 两种网络场景均可复现。

- [ ] T-06 6 处硬编码替换 + 零残留
  关联: R-01, R-02, R-07
  依赖: T-05
  验证方式: `grep -rn "Phoenix Agent\|Phoenix Admin"` 在 `apps/admin-ui/src` 与 `index.html` 的命中数 = **0**
    （默认值常量除外，需列出白名单文件）；登录页、侧边栏、协议弹窗、隐私页、服务条款 5 处逐一 DOM 断言显示新名称。
  验收标准: grep 零残留 + 5 处显示一致。

- [ ] T-07 管理页「外观设置」（名称/主色/Logo/favicon 上传 + 预览 + 保存）
  关联: R-01, R-02, R-03, R-06
  依赖: T-03, T-04
  验证方式: 页面可保存成功并提示；保存后刷新登录页与后台均变化；非法输入有前端提示；
    **普通管理员看不到该菜单/进入被拒**；保存失败（如断网）必须弹 `ElMessage.error`（不得静默）。
  验收标准: 保存链路 + 越权隐藏 + 失败可见 三证。
