# 需求规格：品牌外观配置化（brand-configuration，BL-66）

## 背景与现状

系统名称、Logo、主题色目前**全部硬编码在前端源码**，换客户/换项目必须改代码重新构建。
实测清点（2026-10-25）：

| 位置 | 当前硬编码 |
|---|---|
| `apps/admin-ui/index.html` | `<title>`、`meta keywords="Phoenix Admin"`、`<link rel="icon" href="/favicon.ico">` |
| `views/auth/components/BrandPanel.vue` | 登录页品牌名 `Phoenix Agent`（logo 文案）、版权 `© {year} Phoenix Agent` |
| 登录页 Logo 图片 | `/imgs/logo.png`（静态资源） |
| 侧边栏 / 页面标题 | Vben 布局标题（应用名） |
| 主题色 | `src/preferences.ts`（Element Plus / Vben 主题主色） |
| 协议弹窗 | `PolicyDialog.vue`、`views/front/privacy-agreement.vue`、`views/front/terms-of-service.vue` 正文里的 `Phoenix Agent` |

**目标**：把「系统名称 / 图标（Logo+favicon）/ 主题色」变成**配置项**，交付给客户后可自行改，不必改代码重新构建。

## 需求条款（EARS）

- **R-01 系统名称**：WHEN 配置了系统名称, 系统 SHALL 在**登录页品牌区、侧边栏/应用名、浏览器标签标题**三处统一使用该名称。
- **R-02 图标与 favicon**：WHEN 配置了 Logo 与 favicon, 系统 SHALL 用其替换默认图片与 favicon；未配置时使用内置默认图。
- **R-03 主题色**：WHEN 配置了主题主色, 系统 SHALL 用该色作为全站主色，并**自动派生** hover/active/禁用等色阶（不要求逐色配置）。
- **R-04 默认回退**：WHEN 未做任何配置, 系统 SHALL 呈现与现状**完全一致**的品牌外观（默认值 = 现在的硬编码值），不改变既有观感。
- **R-05 生效方式**：WHEN 配置变更并保存, 系统 SHALL 在用户**刷新页面后**生效，**不需要重新构建前端或重启后端**。
- **R-06 变更权限**：WHEN 非超管尝试修改品牌配置, 系统 SHALL 拒绝并提示无权限；变更须记操作人与时间（审计）。
- **R-07 协议文案联动**：WHEN 系统名称被修改, 系统 SHALL 使隐私协议/服务条款里的平台名同步为新名称（不出现"旧品牌名残留"）。
- **R-08 不破坏功能**：WHEN 品牌配置生效, 系统 SHALL 保持既有功能、权限、路由与布局不变（回归：登录/对话/知识库/组管理）。

## 验收场景

**R-01/R-02/R-04**
- GIVEN 未配置任何品牌项，WHEN 打开登录页与后台, THEN 显示与现状完全一致（Phoenix Agent + 原 logo + 原主题色）
- GIVEN 把系统名称改为「××标准院智能平台」, WHEN 刷新登录页/后台, THEN 登录页品牌区、侧边栏标题、浏览器标签三处均显示新名称

**R-03**
- GIVEN 主题主色改为 `#1f6feb`, WHEN 打开列表/按钮/菜单, THEN 主按钮与选中态为新色，hover/active 为其派生色（不是同一色）

**R-05**
- GIVEN 修改名称与主色并保存, WHEN 刷新页面（不重新构建、不重启后端）, THEN 新外观立即生效

**R-06**
- GIVEN 普通管理员账号调用品牌配置保存接口, THEN 返回无权限（不落库）

**R-07**
- GIVEN 系统名称改为新名, WHEN 打开隐私协议/服务条款, THEN 正文平台名为新名称

## 非目标（本 spec 不做）

- 不做**完整主题编辑器**（暗色模式、字体、圆角、间距等暂不做）
- 不做**多租户多品牌**（一套部署一套品牌）
- 不做**邮件/短信模板**里的品牌替换
- 不做前端整站皮肤热插拔（CSS 变量即可）
- 不改 logo 图片的 CDN/对象存储方案（沿用现有静态资源 + 上传目录）
