=== T-05 验证结论：附件归属鉴权 + 下载/缩略图端点（R-11，L-58 成对实施）===

断言口径: 业务字段 + 响应体身份（L-26/L-37），不以 HTTP 状态码单独定性

--- 实现 ---
- Service: requireAccessible(id, viewer, superAdmin)（不存在→404；非本人且非超管→403 并留 WARN 日志）、
  listForSession(sessionId, ownerIdOrNull)（普通用户仅本人；超管 null=不过滤）、
  openResource（**路径只取库中 storage_path**，L-19）、buildThumb（ImageIO 缩放至 ≤256px；无 reader 如 webp → 回退原图字节）
- Controller: GET /api/chat/attachment（列表）、GET /{id}（下载）、GET /{id}/thumb（缩略图，仅 IMAGE）；
  超管判定复用 AdminRoleGuard（R-08/R-17/R-18 同一口径，不新造）；登录态用 phoenix-token 反查（L-65）
- 加固: 下载与缩略图均加 `X-Content-Type-Options: nosniff`；下载强制 `Content-Disposition: attachment; filename*=UTF-8''…`

--- ② 下载原件：三身份 ---
  chenzhuo → HTTP 200，CD="attachment; filename*=UTF-8''sample.docx"，nosniff=nosniff，**PK 魔数=True（真文件 36670B）** ✅

      安全属性由 `attachment` + `nosniff` 保证，不内联、不嗅探；此为框架行为非缺陷，如实记录。

--- ⑧ 我自己的两处断言错误（如实留痕，均已修正后重跑）---
  1) 断言下载 CT 必须是 octet-stream ⇒ 实为资源真实类型（Spring 覆盖）。任务要求的是 **CD=attachment**，已满足；
     改为断言安全属性本身（attachment + nosniff + PK 魔数）。
  2) 断言"无 token → HTTP 401" ⇒ 实为 HTTP 200 + 业务 code 401（L-26）。**差点误判为鉴权失效**；
     改为断业务码 + 断响应体未含文件魔数（L-37 响应内容身份）。

  避免 token 落访问日志）。该注记已写入 VO 注释与 T-07 验证方式。
