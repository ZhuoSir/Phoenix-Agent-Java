[2] BUG-123 修复（默认角色大小写）
  旧: `eq(PrivilegeRole::getSn, "common")` 生成 `sn = 'common'`（大小写敏感）→ 库里 `COMMON` 永不匹配
  新: Java 侧 `"common".equalsIgnoreCase(sn)`（同 LoginServiceImpl.isSuperAdmin 思路）
  **实证（T-13_sql-probe.txt）**：`sn = 'common'` → **false**；`upper(sn) = 'COMMON'` → **true**

[5] **阻塞项与顺序依赖（重要，明确记载）**
  `tbl_privilege_user` 的 NOT NULL 列实测为：`id / code / username / company_id / dept_id`
  ⇒ 表单去掉组织字段后，**建号会在数据库层被 `company_id` NOT NULL 拦下**
  （探针首轮即为 `ERROR: null value in column "company_id" violates not-null constraint`）。
  必须由 **T-14 的 DDL** 一并解除（DROP COLUMN 或 DROP NOT NULL）。
  已在 `tasks.md` 的 T-14 下追加 Implement 期注记（不改验收口径），并锁定顺序 **T-14 → T-16**。
