=== T-10 验收结论（预设问题接口角色校验 / R-08 / BUG-122）===
日期: 2026-10-07 | 工具链: JDK 23 + Maven 3.8.6 + .mvn-home

[1] 改动
  新增 phoenix-data-core/.../component/AdminRoleGuard.java：
    - `isAdmin(userId)`：裸 SQL 查 `tbl_privilege_user_role ⋈ tbl_privilege_role`，
      判定「硬编码超管 role_id（沿用 AgentKnowledgeMapper 既有口径）**或** `upper(sn)='ROLE_ADMIN'`」
      —— 与 LoginServiceImpl.isSuperAdmin **同口径**（含忽略大小写，规避 BUG-123 类坑）
    - **fail-closed**：SQL 异常时记 error 日志并返回 false（拒绝而非放行），无 userId 直接 false
  改 phoenix-data-rest/.../AgentPresetQuestionController.java：
    - 注入 AdminRoleGuard；新增私有 `requireAdmin()`
    - `POST /{agentId}/preset-questions`（batchSave）与 `DELETE /{agentId}/preset-questions/{questionId}`
      在方法体起始处调用 `requireAdmin()`
    - **校验刻意置于 `try` 之外**：该方法的 `catch (Exception)` 会把异常包成 500
      （"保存预设问题失败: …"），若放在 try 内则 403 语义失真
    - 非管理员 → 抛 `ResponseStatusException(HttpStatus.FORBIDDEN, "权限不足：仅管理员可管理预设问题")`
      → 由既有 `GlobalExceptionHandler.handleResponseStatusException` 统一渲染为
      HTTP 403 + `ApiResponse.error(reason)`（统一错误响应；未登录则由 NotLoginException → 401）
