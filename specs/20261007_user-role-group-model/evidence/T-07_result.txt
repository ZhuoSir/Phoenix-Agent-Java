=== T-07 验收结论（菜单与权限位按角色过滤）===
日期: 2026-10-07 | 工具链: JDK 23 + Maven 3.8.6 + .mvn-home

[1] 改动（唯一入口 LoginServiceImpl + 3 个新辅助方法）
  - getUserMenus()：不再 `list()` 全量 + 满权限位；改为
      超管 → 全部存活菜单 + 全权限位；其他 → 按角色 ACL 实时合并（复用既有 buildUserAclMap）
  - 新增 isSuperAdmin()：硬编码超管 role_id（沿用 AgentKnowledgeMapper 既有口径）
      **或** sn=ROLE_ADMIN（忽略大小写）双条件豁免，避免单一口径失配
  - 新增 filterGrantedModules()：只留有授权的菜单，并**向上补全祖先目录**
      （否则"授了子菜单、父目录未授权"时，子菜单既不成根也不挂父 ⇒ 前端树里静默消失）
  - 新增 resolveGrantedPvalues()：按钮级只下发"角色实际授予的位"对应的 pvalue
  - buildModuleTree()：每菜单带 pvalues（enabled=该位是否授予），兑现 ModuleTreeVO 既有契约
  - 删除 session ACL 快照路径（LOGIN_ACLS 的写/读 + getAclsFromSession 全删）⇒ **改角色无需重登**
  - 加固：多角色合并时 aclState=null 按 0 处理（原实现会拆箱 NPE）
