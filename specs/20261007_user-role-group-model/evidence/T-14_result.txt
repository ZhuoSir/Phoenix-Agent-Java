[5] **演练中抓到并修掉的两个真问题（本任务价值所在）**
  ① rollback 结构恢复与 T-01 dump 的 `CREATE TABLE` 冲突 ⇒ 数据回填静默失败（行数 0）。
     改为**自包含**回滚件：结构(`IF NOT EXISTS`) + 列值(9 条 UPDATE) + 行数据(内联 dump 的 COPY 原文，
     经「临时表 + ON CONFLICT (id) DO NOTHING」保证可重入)。行数核对 4/17/14/0 全部对齐。
  ② 全新库重放 `exit=3`：`ALTER TABLE tbl_unified_account_map ...` 因该表**不在基线**而中断
     —— `DROP COLUMN IF EXISTS` 不保护"表不存在"。已全量改为 `ALTER TABLE IF EXISTS`（正反向对称），
     并在正向件 header 写明该实测注记。教训记 **L-49**。
