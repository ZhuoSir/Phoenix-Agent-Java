## 2. 模型管理（启用集合 / 默认）

- [x] T-04 模型管理接口：启用不再互斥、新增停用（默认保护）、新增设为默认（事务清旧+自动启用）
  关联: R-10, R-11, R-12, R-13, R-14
  依赖: T-03
  验证方式: curl 序列并逐条 psql 复核：① 两条 CHAT 依次 `activate` → 两条 `is_active=true` 且都不被停用；② `default/{A}` 后 `default/{B}` → 仅 B 为默认、A/B 启用态不变、EMBEDDING 默认不受影响；③ `deactivate/{B}`（B 是默认）→ 返回 42014 且库中 B 仍启用；④ 对未启用配置设默认 → 自动置启用；⑤ 连续两次并发设不同条为默认 → 最终仅一条默认（唯一索引 + 事务，无 500）
  验收标准: 每类型至多一默认由 DB 保证；设默认即启用；停用默认被拒绝且提示可展示；错误经统一信封返回不含堆栈

- [x] T-05 模型管理前端：默认标记列 + 「设为默认」+ 启用文案去互斥 + 停用被拒提示
  关联: R-10, R-11, R-12, R-13, R-14
  依赖: T-04
  验证方式: 人工走查（管理端模型配置页）：① 列表可见"默认/—"标记且同类型仅一条默认；② 依次启用两个 CHAT → 两行都显示已启用；③ 点「设为默认」后旧默认标记迁移；④ 点停用当前默认 → 弹出后端提示文案（42014）而非"成功"；⑤ 原确认框文案中"同类型其他将被停用"字样不再出现
  验收标准: 界面与后端语义一致（无"启用会停用其他"的残留暗示）；`npx vue-tsc --noEmit` 改动文件 0 错误

## 4. AI 生成能力（后端）

- [x] T-07 生成错误码枚举 + md 骨架与 meta-prompt 常量类 + `GET /api/agent/generate-profile/skeleton`
  关联: R-06, R-08, R-18

  验收标准: 错误码集中在枚举（42010~42015）不散落字符串；段落集合单一来源；骨架无 TODO/空段落

- [x] T-08 生成服务：取 CHAT 默认 → 一次调用出描述+提示词（JSON 协议）→ 解析/超时/失败错误码
  关联: R-01, R-03, R-04, R-06, R-18
  依赖: T-07
  验证方式: 真实调用服务（经 T-09 端点）：① 名称「合同审查助手」→ 返回两项非空，提示词含四段且为 md；② `targets=["PROMPT"]` 单项 → 只返回提示词；③ 人为把 api_key 改错 → 返回 42012 且响应无堆栈、无半成品；④ 无 CHAT 默认 → 42011 引导文案；⑤ 模型返回带 ```json 围栏/夹带说明文字 → 仍能解析或明确 42013（原文只进日志）
  验收标准: 中文、描述 ≤120 字纯文本、提示词 md 300~600 字四段齐全；失败一律可展示错误码；日志含 traceId/配置ID 不含 api_key；超时 ≤60s 返回

- [x] T-09 `POST /api/agent/generate-profile` 端点与入参校验（不自动保存）
  关联: R-01, R-02, R-03, R-04
  依赖: T-08
  验证方式: curl：① 正常入参 → `ReturnVo` 成功且**保存前** `select prompt,description from tbl_data_agent where id=?` 未变化（证明不自动保存）；② `name` 空 → 42010；③ `name` 超长/`targets` 空或含非法枚举 → 参数错误；④ 未登录 → 未授权；⑤ 生成后手工 PUT 保存 → 落库为返回的 md 原文（含 `##` 标题字符未被转义）
  验收标准: 服务端校验一切入参；DTO/VO 不裸 Map、VO 不含敏感字段；不改动智能体记录（无副作用）

  依赖: T-07
  验证方式: 人工走查：① 直接写 `**加粗**` / `- 列表` / ``` 代码块 在预览正确渲染；② 三态切换（编辑/分栏/预览）无内容丢失；③ 工具栏各按钮在光标处插入且不吞已输入内容；④ 「插入骨架」得到四段模板；⑤ 粘贴含 `<script>alert(1)</script>` 的 md → 预览不执行（html:false）；⑥ 传入存量纯文本（无 md 语法）正常显示不报错；⑦ 字数与四段缺失提示出现但不阻断

  依赖: T-09, T-10
  验证方式: 人工走查（编辑抽屉基本信息区 + `/agent/:id`）：① 提示词框为 md 编辑器、描述框仍是纯文本；② 填名称点「同时生成两项」→ 两字段回填、保存前不写库；③ 目标字段已有内容时弹确认，取消后原文保留；④ 生成后可「撤销」恢复点击前内容；⑤ 只对提示词单项生成时描述不动、两者 loading 独立；⑥ 无 CHAT 默认时提示引导文案、表单不变
  验收标准: 覆盖必确认、失败不清空、不自动保存；生成产物的 md 原文与保存后库内值逐字一致

- [x] T-12 运行配置面板模型下拉改为「启用集合」+ 空值显示"默认（模型名）"
  关联: R-15, R-16
