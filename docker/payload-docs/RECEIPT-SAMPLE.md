# 收据卡样例（install.sh 成功时自动打印并写入包根 RECEIPT 文件）

```
======================================================
  Phoenix 安装收据 —— 安装成功
======================================================
  版本: 1.5.0
  架构: amd64
  访问地址: http://localhost:9080
  管理端账号: admin / 123456（首登立即改密）
  库密码: <随机32位hex>（仅此一次，已存 docker/.env）
  数据目录: docker 卷 phoenix_*（/var/lib/docker/volumes/）
  日志: /home/<user>/.phoenix/install-20261003-150000.log
======================================================
```

- **库密码只回显这一次**——丢了看 `docker/.env` 的 `PG_PASSWORD`（权限 600）
- 日志文件包含九步全程时间戳，报障时请附尾部 30 行
- 下一步三件事：改密 → 配模型 API key → 跑一次 `sh docker/scripts/verify.sh` 留底
