## 二、行为变更（用户可感知）

1. **登录/账号**：后台单套登录；前台 `POST /auth/login` 保留（内部走同一认证实现）；账号 id 唯一化。
2. **智能体中心**：在新浏览器窗口打开独立 chat 页；该页**不再有「系统设置」入口**；左侧菜单由 DB 数据驱动。
3. **知识库访问**：
   - `GET /uploads/data-agent/agent-knowledge/**` 与 `/uploads/agent-workspace/**` → **404（且响应体不含正文）**；
   - 原件改走 **`GET /api/agent-knowledge/{id}/raw`**（校验登录 + 归属/绑定 + 审计）；
   - 头像等既有 `/uploads` 图片用途**不受影响**（实测 200）。
4. **模型配置**：新增配置不再"静默失败"（BUG-106：前端 id 残留 + 假成功提示 + 服务端 `setId(null)` 加固）。
5. **智能体运行页**：显示**智能体真实头像**（BUG-110，消息区 + 侧栏两处）。
