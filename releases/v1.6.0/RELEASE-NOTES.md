- 工作区布局 v2：`{root}/{agentKey}/{sessionId}`（框架内再拼 `{uid}`）——**每智能体每会话独立文件夹**
- shell cwd 统一到会话目录（修 BUG-79：此前 shell 落在容器根 `/app`，产物逃逸且面板不可见）
- 读路径统一：产物扫描以会话目录为根递归；`runtimeKey` 以库中智能体为准（修 BUG-78 真根因）
- 存量迁移 runner（`_legacy_shared/` 归档，幂等）+ `/app` 散落清理；**零 DDL**

### 4. 长轮可靠性（specs/20261005_long-turn-resilience · 7/8）
- 看门狗活性化：空闲 600s 才判挂起；总时长闸默认关（长活轮不被腰斩）；中断原因五分类文案
- 服务端 100ms 帧合并（实测 600→6.6 帧/秒）+ 前端增量渲染 → 长轮期间浏览器可交互
- **join 追流**：运行中刷新/重进 → 服务端 replay + live **原地续渲**（不再 5s 轮询跳变）
- 上下文治理可配：压缩触发 token / 保留条数 / 工具结果截断（agent 配置 → 全局 env 默认两级回退，三列进实例指纹）
- 状态修复（BUG-77 根治）：轮次开始前修复「仅 tool_use 无 thinking」的助手消息
