# v1.2.0 升级说明（2026-09-30，M3 汇总；发版日期以 tag 为准）

## 新增
- **技能管理**：技能 ZIP 上传自动识别、发布/下线/删除、按用户组授权、按智能体绑定；前台对话新增技能区与单轮显式执行（上限默认 3 个）
- **对话智能体运行配置**：按智能体独立配置——对话模型（可选，未选走默认）、知识库检索参数（topK/相似度阈值）、数据库取数、数据库深度分析、计划模式、记忆、文件系统策略；保存后下一轮对话生效
- **AI 生成智能体描述与提示词**：按名称一次生成「描述（纯文本 ≤120 字）+ 提示词（Markdown，含 角色/描述/能力/安全范围 四段）」；使用模型管理中的**默认对话模型**；结果只回填表单，点保存才生效；支持覆盖确认与撤销
- **模型管理「默认模型」**：CHAT/EMBEDDING/AUDIO 每类型至多一条默认（数据库唯一索引兜底）；「启用」改为可多选集合；设默认即自动启用；未显式选模型的运行时按类型默认加载
- **提示词 Markdown 编辑**：自研轻量 md 编辑器（编辑/分栏/预览三态 + 工具栏 + 骨架插入 + 字数与缺段提示），零新增前端依赖；存储与下发仍为 md 原文
- **一键部署交付包**（docker/ 目录）：compose 编排 nginx/backend/pg/redis/初始化器，仅 9080 对外；首启自动建库(基线+种子+本版本升级件)；离线 save/load 交付；备份/升级/回滚/断言脚本与 README 齐套（本版本纳入经用户 09-30 明示，自拟 v1.2.1 挤入）

## 变更
- 智能体列表移除四个类型标签，且**仅显示平台内创建的智能体**；存量 5 个 Java 自注册智能体仍可正常对话，但不再出现在列表（可从历史会话进入）
- 模型「启用」不再互斥（原：启用 A 会停用同类型其他）→ 多条可同时启用；取模型改判「默认」，无默认时回落任一启用并 WARN
- 后台新建智能体固定为「对话智能体」类型；运行页按类型分流并以 agentId 寻址
- 描述/提示词生成入口合并为单按钮「AI 生成描述与提示词」（用户决议，AC-04 前提随之变更；API 层单项 targets 保留）

## 修复
- BUG-01 基线 `all_schema.sql` 缺 5 个序列 → 全新环境导入必失败（已空库复验零报错）
- BUG-06 技能无管理入口且技能池全局共享
- BUG-07 shell 能力与远程文件系统硬绑互斥、无开关
- BUG-09 前台与 harness 智能体无对话通道
- BUG-10 后台新建智能体 type 为空、无法创建对话智能体
- BUG-12 只读 SQL 被安全校验子串匹配误杀（`create_time` 等）
- BUG-13 EMBEDDING 模型测试恒 404（base_url 多带 `/v1` + 模型名不被兼容模式支持）
- BUG-15 智能体列表关键字搜索 PG 下 500
- BUG-16 三张向量表缺主键 → `ON CONFLICT` 必失败
- BUG-17 图链路在非 HTTP 调用方取登录态抛异常
- BUG-19 harness 对话入参缺失返回 500（改明确错误码 400）
- BUG-20 启用模型会把同类型其他模型一并置为启用（SQL 与注释相反）
- BUG-22 AI 生成「描述」返回整段 JSON
- BUG-23 生成超时 60s 切断已成功的调用（放宽为默认 90s 且可配置）
- BUG-26 技能上传缺 multipart 头 → HTTP 415
- BUG-27 技能 ZIP 校验报错信息误导
- BUG-28 `ReturnVo.ok(String)` 重载误用丢 data
- BUG-29 组授权表 agent_id 类型比较报错（代码侧绕过，列类型根因留档 BL-07）
- BUG-30 AI 生成前端全局 30s 超时掐断（生成接口单独 120s）
- admin-ui 生产构建失败：`json-bigint` 被 request.ts 使用但未在 package.json 声明（dev 侥幸、build 必挂；docker 交付包实测暴露，随交付包分支修复）

## 已知问题与注意事项
- 换 EMBEDDING 默认/地址后，**历史向量需重新初始化**才能与新模型一致（接口已有 WARN 提示）
- 响应式超时**无法中断**底层已发出的模型调用（超时后 token 仍会消耗完）——已接受的技术债（BUG-24，转 P3）
- 存量 5 个自注册智能体不出现在列表属**设计使然**（如需管理它们见 BL-12 讨论）
- 提示词 md 化仅约定编辑器与生成产物形态，**不做渲染强制**：存量纯文本提示词原样可用（AC-13 实测）
- `tbl_platform_group_agent_info.agent_id` 列类型不一致根因仍在（BUG-29/BL-07，建议后续统一 bigint）
