## 二、行为变更（用户可感知）

### 2.1 用户与权限体系（**破坏性**）

1. **组织维度下线**：企业（`tbl_privilege_company`）、部门（`tbl_privilege_department`）、员工（`tbl_privilege_employee`）三表及其在用户表上的归属列全部删除；后台不再有企业/部门/员工菜单与页面。
2. **用户体系 = 用户·角色·组**：用户只归属**组**；**组直接关联**智能体、技能、知识库、MCP 插件，组内用户据组获得资源可见性（原「后台数据组」死代码一并清理，组语义唯一化）。
3. **菜单按角色过滤生效**：原先菜单对所有登录用户可见，现按角色授权过滤；越权 URL 返回 404。
4. **登录方式收敛**：**只保留账号密码登录**；三方平台用户/组织同步、第三方免登（应用内 SSO）、三方平台配置 CRUD 与页面菜单**全部下线**。
5. **信息架构调整**：原「权限管理」+「前台管理」合并为 **「系统管理」**。
6. **账号集合收敛**：仅保留内置超管 `admin` 与实际在用账号；`user_type`（自建/IDM）与工号（`code`）维度下线。
7. **内置超管保护**：`admin` 不可删除；删除账号/删除角色端点加保护（不可删自己、不可删最后一个超管、不可删「系统管理员」角色）。
8. **资源归属**：智能体列表按创建人可见；知识库/技能/MCP 对齐同一归属口径（own ∪ myGroups ∪ public）；技能名称唯一性改**按创建人隔离**（跨用户同名允许）。

### 2.2 对话附件

9. **附件上传**：对话中可上传文档（`.docx/.pdf/.xlsx/.txt/.md`）与图片（常见格式），白名单外**一律提示不支持**；受大小与数量限制。
10. **内容理解**：文档解析为文本后与提示词一并提交模型；图片走**真多模态视觉模型**（`model_type=VISION` 家族）；视觉模型缺失或调用失败时**降级但显式提示**；超长内容截断并告知；解析失败给出明确提示。
11. **持久化与回看**：附件落盘持久化，历史会话可回看；访问受归属校验。
12. **两端一致**：admin-ui 与 mobile-ui 行为一致。
13. **会话空间隔离**（CR-03）：后台「运行」页（测试管理）与前台 chat（含 mobile）**互不可见**彼此会话；跨空间访问按 404-as-不存在处理。

### 2.3 模型接入（Ollama）

14. **新增 Ollama 提供商**：模型配置页可选 Ollama，**API Key 可留空**；支持本机模型列表拉取与连通性测试（覆盖全部模型类型）。
15. **对话与工具调用**：Ollama 模型可用于对话（含流式）与工具调用；能力差异有降级提示；离线/内网环境可用。
16. **向量维度**：Embedding 维度不再硬编码 512，改由**维度解析器**按模型实际维度决定（支持 768）；**维度不一致时显式拒绝**（防脏数据写入）。
